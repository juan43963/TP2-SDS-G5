## Planner decisions (Claude's discretion — no CONTEXT.md for this phase)

- **PD-20 Layout.** The Python layer lives in `ejercicio2/python/`, sibling of `src/`, mirroring `ejercicio1/python/`. The figure style is NOT copied: `ejercicio2/python/plot_style.py` is a shim that loads `ejercicio1/python/plot_style.py` by file path and re-exports its public names by identity, so AN-12 has a single source and every script keeps the plain `import plot_style` of Phase 1.
- **PD-21 Strict readers.** Readers never accept a file without its `# END` trailer and never repair a malformed number: a half-written run (Phase 2 review items WR-03 and WR-04) must be rejected, not analysed. No "incomplete" reading mode exists.
- **PD-22 Energy reference.** The reference energy is the analytic E(0) = N*1/2*m*v0^2 of the non-overlapping initial state (3.75 J for N = 300), and frame 0 recomputed from the snapshot must match it within a declared relative tolerance of 1e-9 (measured by the planner on the real engine: 1.5e-14 at dt = 1e-4 and 2e-13 at dt = 5e-6, because the centred-difference velocity carries ~1e-16/dt of round-off). ε is averaged over the output instants j >= 1 (t > 0) so the exact t = 0 sample does not dilute it.
- **PD-23 Pair search.** Pair energy uses a full N x N distance matrix in numpy with the strict upper triangle (N = 300 gives 45k pairs per frame, N = 650 about 211k: trivial), no spatial index and no scipy. Contact is strict (xi > 0) exactly like the engine.
- **PD-24 Cross-validation exactness.** The conversion-instant recomputation is exact only when the frames file has `every = 1` (the engine tests contact on r_k at every step and frame k stores r_k). With `every > 1` the check degrades to a bracket (previous frame time < logged t <= first frame showing the particle as used) and says so in its output. The CLI/test use a short `every = 1` run (N = 100, dt = 2e-4, tf = 0.5: 21 MB, 8 conversions measured by the planner).
- **PD-25 Reversibility.** The reader API names and the format-version strictness are imported by every Phase 3-6 script: rated `costly` on Task 1.

(1) `ejercicio2/python/tp4io.py`. Module docstring: this mirrors the formats written by ejercicio2/src/billiard/billiard_cli.cpp and documented in ejercicio2/README.md; it is the Python half of a cross-language format coupling with no shared schema, so a format change needs coordinated edits in both languages.
- `class TP4FormatError(ValueError)`; every message names the file (when known), the 1-based line number and the offending token.
- `@dataclass(frozen=True) class RunHeader` with fields N (int), R, radius, mass, k, v0, x0, dt, tf (float), every, max_steps, seed (int), obstacles, stop_when_all_used, stop_at_t90 (bool) and init (str); property `dt2` returns every*dt.
- `parse_header(line, kind)` with kind one of "FRAMES", "CONVERSIONS", "SUMMARY": FRAMES and CONVERSIONS lines must start with the tokens `#`, `TP4_FRAMES` (or `TP4_CONVERSIONS`) and `1`; the SUMMARY line starts with `TP4_SUMMARY` and `1` and has no `#`. The version must be exactly 1. The remaining tokens are `key=value`; duplicate keys, unknown keys and missing keys raise TP4FormatError. Booleans are the strings 0 or 1 only. Validate N >= 1, dt > 0, tf > 0, every >= 1, max_steps == round(tf/dt) and init in {rsa, lattice}. Returns the RunHeader plus the dict of extra keys (empty for FRAMES and CONVERSIONS).
- `@dataclass(frozen=True) class Frame`: step (int), t (float), pos and vel as float64 arrays of shape (N, 2), used as a uint8 array of shape (N,).
- `class FrameReader`: constructor `FrameReader(path)`; context manager and iterator; opens the file in text mode with a 1 MiB buffer; reads and validates line 1 (attribute `header`) and tolerates the second `#` comment line. Iteration yields Frame objects one at a time (never the whole file in memory). Per frame validate: the line is `FRAME {k} {t}` with integer k and finite t, k is 0 for the first frame and then strictly increasing, k % every == 0, |t - k*dt| <= 1e-12*max(1, |t|), exactly N rows follow, each row has exactly 5 tokens parsed with float(), every value is finite, and the used column is 0 or 1. After the last frame the next non-empty line must be `# END frames={n} final_step={k} final_time={t}`, n must equal the frames read, final_step must be >= the last step and nothing may follow; a missing trailer, a truncated frame or an extra line raises TP4FormatError. The parsed trailer is exposed as attribute `end` (dict with frames, final_step, final_time) after the iterator is exhausted, and `None` before. Parse each frame's N rows with `np.array(" ".join(lines).split(), dtype=float)` after taking the lines with itertools.islice, so a bad token raises ValueError that is re-raised as TP4FormatError.

(2) `ejercicio2/python/physics.py`. All parameters come from a RunHeader; no module-level duplication of the engine constants except what the CLI prints.
- `initial_energy(N, mass, v0)` returns N*0.5*mass*v0*v0; `contact_time_pair(mass, k)` returns pi*sqrt((mass/2)/k); `contact_time_wall(mass, k)` returns pi*sqrt(mass/k) (the obstacle contact time is the same as the wall's).
- `@dataclass(frozen=True) class EnergyParts` with floats kinetic, pair, wall, obstacle and properties `potential` (pair + wall + obstacle) and `total`.
- `frame_energy(pos, vel, header)` returns EnergyParts. kinetic = 0.5*mass*sum of |v|^2. pair = 0.5*k*sum of xi^2 over unordered pairs i < j with xi = 2*radius - |r_j - r_i| > 0, using one N x N squared-distance matrix, its strict upper triangle (cache np.triu_indices per N) and a mask on squared distance before the square root. wall = 0.5*k*sum over particles of xi^2 with xi = |r_i| + radius - R, only where positive. obstacle = 0 when header.obstacles is false, otherwise 0.5*k*sum over the two centres (-x0, 0) and (+x0, 0) and over particles of xi^2 with xi = 2*radius - |r_i - c| where positive; a particle touching both obstacles contributes two springs (the engine applies both forces). Each contact is counted exactly once and contact is strict (xi > 0), like the engine.
- `@dataclass class EnergySeries` holding numpy arrays step, t, kinetic, pair, wall, obstacle, total (one entry per frame).
- `energy_series(reader)` iterates a FrameReader and returns the EnergySeries (one frame_energy call per frame).
- `check_initial_energy(series, header, rtol=1e-9)` returns (e0_analytic, relative_error) with relative_error = |total[0] - e0_analytic|/e0_analytic and raises ValueError when it exceeds rtol or when step[0] is not 0.
- `relative_deviation(total, e0)` returns (total - e0)/e0 as an array; `epsilon(total, e0)` returns the mean of |total[j] - e0|/e0 over j >= 1 (PD-22).
- `main(argv=None)`: `--frames PATH` and `--rtol` (default 1e-9). Prints one `key=value` line each for `frames`, `E0_analytic` (%.12g), `E0_recomputed`, `E0_rel_err` (%.3e), `E0_check` (OK or FAIL), `epsilon` (%.6e) and `max_rel_dev` (%.6e); returns 1 when the E(0) check fails and 0 otherwise. Guard with `if __name__ == "__main__": raise SystemExit(main())`.

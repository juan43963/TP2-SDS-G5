<objective>
Build the batch runner that every sweep of Phases 3-5 uses: it launches `billiard` runs in a process pool with deterministic seeds, writes each run to a path that encodes all its parameters (dt included), skips finished runs on relaunch, resumes an interrupted batch, records divergence as a result instead of a crash, and never lets timing runs go parallel.

Purpose: success criterion 5 of Phase 3 (DIF-06, AN-13). The 2.2 and 2.4b sweeps are hundreds of runs, and the TP2 retrospective showed that unencoded parameters mixed truncated and valid runs. A resumable, path-encoded runner is what makes `--replot` and re-launches safe.

## Planner decisions (Claude's discretion — no CONTEXT.md for this phase)

- **PD-30 Directory per run, atomic promotion.** A run writes into `{data_root}/{study}/{name}.partial/` and is promoted with `os.replace` to `{data_root}/{study}/{name}/` only after validation. A final directory therefore implies a finished run; an interrupted or failed run can never be mistaken for a good one (the TP2 failure mode). A failed run is kept as `{name}.failed/` for diagnosis and is retried on relaunch.
- **PD-31 Finished means validated.** `is_complete` re-validates the directory against the spec: summary header equals the spec (N, seed, dt, tf, every, obstacles, x0 when obstacles, stop flags, init), conversions trailer `used` and `final_step` agree with the summary, and the frames file (only when a trajectory was requested) ends with a `# END frames=` line whose final_step agrees. The frames check reads only the last 512 bytes (frames files can reach tens of MB). A `diverged.json` marker whose `name` equals the spec name also counts as finished.
- **PD-32 Divergence is a result.** Exit code 1 plus the substring "no finita" in stderr (DIVERGED_MARKER, matching the two engine messages in simulation.cpp and forces.cpp) means the dt is too large for the dynamics. 2.1a needs that as data (dt = 5e-3 diverges at N = 300). Any other non-zero exit is a real failure.
- **PD-33 Seeds.** Deterministic common seeds `make_seeds(n) = (1, ..., n)`, shared across x0 and N within a study (common random numbers, as in TP3); defined once here and imported everywhere (TP2 lesson).
- **PD-34 Integer output stride.** `every_for(dt, dt2)` computes n = round(dt2/dt) and requires |n*dt - dt2| <= 1e-12 (research Pattern 4), so the same absolute output instants are obtained for every dt.
- **PD-35 Reversibility.** The run-directory naming scheme is read by Phases 4-5 (2.4a reuses 2.1b logs, 2.4b reuses the 2.2 N = 100 row): rated `costly` on Task 1.

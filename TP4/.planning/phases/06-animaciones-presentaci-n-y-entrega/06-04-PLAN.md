## Planner decisions (Claude's discretion: no CONTEXT.md and no RESEARCH.md for this phase)

- **PD-150 Gate first, manual steps after.** The gate is automated and testable now (synthetic PDFs from matplotlib); the manual steps are checkpoint tasks that run the gate as their verification. A human never has to remember a rule: the gate states it.
- **PD-151 Layered "no embedded animation" check.** (1) the deck source has no media package or movie command (06-03 linter); (2) the PDF has no embedded files and no Movie, Screen, RichMedia, Sound or FileAttachment annotation: PyMuPDF when importable (it parses object streams), else `pdfdetach -list` plus a raw-byte scan for those names; the raw scan cannot see names inside compressed object streams (pdflatex 1.5 output), which is why layer 1 exists; (3) `entrega/` holds no MP4, GIF, MOV, AVI, WEBM or PPTX. The residual risk is low because the deck loads only Beamer and hyperref.
- **PD-152 Page count as a completeness check.** Expected pages equal the SLIDE markers (27) plus the section dividers (5) = 32: a missing divider, an overflowing frame or a dropped slide changes it.
- **PD-153 One System 1 page.** The PDF text is scanned page by page for Error cuadrático medio, ECM, Beeman and oscilador: exactly one page may match (the enunciado's single System 1 slide).
- **PD-154 Where each manual step runs.** Figures: assembled on whichever machine, committed by the user, pulled by the compiling machine. Compile: Windows with MiKTeX (any TeX Live or tectonic is acceptable too, only the PDF is delivered). Gate: any machine with Python and `pdftotext` or PyMuPDF; the zip compile check already ran on g++ in 06-02.
- **PD-155 Reversibility.** Registering the links is the only step with a cost to undo (a replaced video means a new upload, a new `links.tex` and a recompile): rated costly on Task 2. Submission itself is re-doable on campus until the deadline; the agent never submits.

- **PD-130 What ships (Q6 default).** Both engines (`osc` for System 1, `billiard` for System 2): PROJECT.md records the oscillator as part of the "motor" that goes in the zip. Layout inside the zip keeps the repository names so every file maps to its source: `Makefile`, `ejercicio1/src/...`, `ejercicio2/src/...`. No README (the enunciado forbids extra documentation): usage is a short comment block at the top of the Makefile.
- **PD-131 One root Makefile.** `entrega/Makefile` is a tracked, readable file with `CXX ?= c++`, `CXXFLAGS ?=` holding the six flags of the engine Makefiles without `-I`, the include directories as separate variables (`-Iejercicio1/src/include`, `-Iejercicio2/src/include`) so a command-line `CXXFLAGS` override (used by the verification to add `-Werror`) keeps them, explicit source lists `OSC_SRC` and `BILL_SRC`, objects under `build/`, targets `all`, `osc`, `billiard`, `clean`. The package test compares its flag tokens with those of both engine Makefiles.
- **PD-132 Deterministic archive.** Members sorted, `ZipInfo` with a fixed `date_time` (`ZIP_TIMESTAMP = (2026, 10, 1, 0, 0, 0)`), `create_system` 3, `external_attr` 0o644 shifted 16, DEFLATED, text normalized CRLF to LF, no extra fields. Reason: no user or time metadata leaks and the sha256 is reproducible.
- **PD-133 Frozen-engine proof.** The zip is the final version of the engine, i.e. the frozen one: each ejercicio2 file's normalized sha256 must equal `engine_freeze.json["files"]`, and `git` (read-only) must report the engine sources and the Makefiles unmodified against HEAD. The oscillator is not in the freeze, so only the git check applies to it. `--no-git-check` exists for a tree without git.
- **PD-134 Compiler of the verification.** The verification uses `c++` by default (Apple clang 21 here, g++ 13.3 on the group machine) with `-Werror` added so any warning fails; `--cxx g++` selects the WSL compiler. Warning-free on clang does not prove warning-free on g++, so the g++ run is a human check (the sources are the frozen ones, whose `make strict` on g++ 13.3 passed in Phase 4).
- **PD-135 Size limit.** The enunciado says smaller than 100 KB; the script asserts strictly below 100000 bytes (decimal, conservative). Expected size is about 20 KB.
- **PD-136 Reversibility.** Zip layout and contents are cheap to redo: no rating beyond reversible.

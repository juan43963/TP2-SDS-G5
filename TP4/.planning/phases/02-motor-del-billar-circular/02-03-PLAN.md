## Planner decisions (Claude's discretion — no CONTEXT.md for this phase)

Lattice numbers were computed by the planner with a Python replica of exactly this construction (scratch only, not in the repo).

- **PD-12 Lattice**: a triangular lattice anchored at the origin.
  - **Geometry**: spacing a = 2r + 1 mm = 0.036 m, row height h = a·√3/2, odd rows shifted by a/2.
  - **Valid site**: |s| ≤ R − r − J and |s − (±x0, 0)| ≥ 2r + J, with J = 0.5 mm.
  - **Selection**: N sites drawn uniformly without replacement (std::shuffle with the run's mt19937_64), each jittered uniformly in a disk of radius < J. Pair distance stays > a − 2J = 2r, so the state is overlap-free by construction and passes verifyInitialState exactly.
  - **Capacity** (replica): 666 at x0 = r, 667 at x0 = R − r, a minimum of 665 at x0 ≈ 0.041 over a 41-point x0 grid, and 673 without obstacles. All are ≥ 650.
  - A smaller gap (0.5 mm → 684 sites) would leave almost no jitter. A larger one (2 mm → 641) would not reach 650.
- **PD-13 `--init auto`** is the default. It uses RSA for N ≤ 400 and the lattice above. This matches research SUMMARY conflict #5 and ENG-02 "red para N > ~400".
  - If RSA exhausts its attempts in auto mode, the generator falls back to the lattice with a freshly seeded RNG. The fallback state is therefore identical to `--init lattice` with the same seed.
  - Explicit `--init rsa` never falls back.
  - The resolved method is what `init=` records, so Phases 4–5 can disclose it. 2.1b/2.4a will pass `--init lattice` for every N, which is a Phase 4 rule.
  - Rated reversible: one function, and the threshold is a constant.
- **PD-14 Capacity check first**: N > latticeCapacity(p) throws std::invalid_argument containing "capacidad" for every mode, before RSA or any file. Nothing can place more than the lattice, since RSA saturates far below it.
- **PD-15 Cost measurement**:
  - runs: `--init lattice --dt 1e-4 --tf 10 --no-trajectory`, seeds 1–3, N ∈ {100, 600}, serial;
  - cost per particle-step = simulation_ms·1e6 / ((final_step + 1)·N) ns; cost per step = simulation_ms·1e3 / (final_step + 1) µs;
  - linear-scaling criterion: N600/N100 ratio within [0.5, 2.0]. The research prototype measured 16–18 ns at N = 100…650.
  - The final values for Phase 4 are re-measured there on the frozen engine. These numbers size the Phase 4–5 grids.

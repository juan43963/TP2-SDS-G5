## Fundamentos matematicos (referencia unica de la Fase 7)

Notacion: tau = `config.sfm.tau`; v_d = `config.sfm.desiredSpeed`; e = versor del agente hacia su target actual; w = v_d*e (velocidad deseada, constante entre eventos); Delta = v0 - w; u = t - t0 (tiempo desde la ultima sincronizacion del agente); E(u) = exp(-u/tau).

- Trayectoria exacta (D-13, D-17): v(u) = w + Delta*E(u); x(u) = x0 + w*u + Delta*tau*(1 - E(u)). Es la solucion analitica de la fuerza de deseo de D-05 sin contacto: `forces.cpp` la integra numericamente y EDMD/hibrido la evaluan en forma cerrada.
- Agente libre (D-14): Delta = 0, la trayectoria es una recta a velocidad w.
- Movimiento relativo: para dos agentes con la misma referencia de tiempo, D(u) = x_b - x_a tiene la misma forma con w_rel = w_b - w_a, v0_rel = v0_b - v0_a. Una esquina (punto fijo) es el caso x_a = P, w_a = 0, v0_a = 0.
- Evento de contacto con aproximacion: primer t >= tStart tal que |D(t)| <= R + kContactTolerance y la tasa d|D|/dt = D.V/|D| es negativa. Si en tStart ya hay contacto pero se separan, no hay evento hasta que salgan y vuelvan a entrar; si en tStart hay solape y se aproximan, el evento es tStart.
- Cruce de plano: s(u) = n.x(u) - offset = S0 + a*u + b*(1 - E(u)); s' = a + (b/tau)*E(u) es monotona, de modo que s tiene a lo sumo un extremo y se resuelve por tramos monotonos.

Casos: (a) si |Delta_rel| <= 1e-12 (ambos libres, D-14) forma cerrada: resolver |D(tStart) + w_rel*s|^2 = R^2 con la cuadratica de TP3 `collisionRoot` (aproximacion si D.w_rel < 0) respetando la semantica de contacto con separacion y solape; (b) si no, avance seguro de segundo orden sobre el tramo transitorio [tStart, t0 + kSettleTaus*tau]: con r = |D|, g = r - R, g' = D.V/r y B una cota de |g''| <= (|V|^2 - g'^2)/r + |A| calculada de |V(t)| <= |V_k| + a_k*h y |A| <= a_k = |Delta_rel|*E_k/tau sobre una ventana h_cap = 0.05 s con r_min = max(r - (|V_k| + a_k*h_cap)*h_cap, 0.5*R), el paso certificado es la raiz positiva de g + g'*h - B*h^2/2 = 0 (cota inferior parabolica de g); parar con exito cuando g <= kContactTolerance y g' < 0; si g <= kContactTolerance y g' >= 0 avanzar con el mismo paso certificado (tocando y separandose) o con el paso minimo 1e-7 s si el certificado da 0; tope de 10000 iteraciones que suma a `kernelIterationCaps()` y devuelve `kInfinity`; (c) agotado el transitorio sin contacto, resolver la recta asintotica con el estado exacto en ese instante (misma cuadratica que (a)).
